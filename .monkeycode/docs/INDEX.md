# mqttc 文档

## 项目概述

mqttc 是跨平台桌面 MQTT 调试客户端，界面参考 MQTTX。用户通过图形界面同时维护多条 Broker 连接，订阅 Topic、发布消息、观察日志，并为每条连接配置发布预设与自动回复。

**目标用户**: 需要快速验证 MQTT 连通性与消息流的开发者、测试与运维人员

**核心价值**:
- 打开即可连接、订阅、发布，覆盖日常调试最短路径
- 基于 Rust 与 Slint，同一套代码覆盖 Windows、macOS、Linux
- 多连接并行在线，每条连接有独立日志、发布预设与自动回复规则
- 消息日志即时可见，便于对照 Topic 与 Payload
- 以 MIT License 开源，全文见仓库根目录 `LICENSE`

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 语言 | Rust 2021 | 跨平台、内存安全、适合长期运行的网络客户端 |
| UI | Slint 1.18，软件渲染 | 声明式桌面 UI，官方支持 Win/macOS/Linux；软件渲染降低启动内存 |
| MQTT | rumqttc 0.24 | MQTT 3.1.1 与 5.0 共用同一套会话封装 |
| TLS | rustls | 可选校验证书、自定义 CA、客户端证书 |
| 配置 | 可执行文件旁 `mqttc.json` | 便携，无需查用户主目录 |
| 首发平台 | Windows / Linux 预编译，macOS 本机编 | Linux 环境无法交叉编译 Darwin |

## 核心功能

### 多连接配置管理
- **目的**: 同时维护多个 Broker 配置，按需切换或并行调试
- **描述**: 左侧连接列表支持新建、选择、删除。界面分为连接配置页、会话页、自动回复页、发布预设页、设置页与关于页。每个连接独立保存地址、认证、订阅、发布、预设与自动回复，并可同时保持在线

### 连接 Broker
- **目的**: 与 MQTT Broker 建立 TCP 或 TLS 会话
- **描述**: 用户填写主机、端口、Client ID，可选用户名和密码，选择 MQTT 3.1.1 或 5.0 后一键连接或断开。高级参数可设置 Keep Alive、连接超时、Clean Session（MQTT 5.0 对应 Clean Start）、SSL/TLS 与 Last Will；Client ID 留空则自动生成。勾选 SSL 会把默认端口切到 8883

### 订阅 Topic
- **目的**: 接收指定主题的消息
- **描述**: 已连接状态下订阅 Topic（支持 `+` / `#` 通配符），可为每次订阅选择 QoS 0/1/2。支持同时订阅多个，每个订阅可单独取消。点击某条订阅可按该过滤器筛选日志，再点一次取消。重连后自动恢复订阅

### 发布消息
- **目的**: 向 Broker 发送调试消息
- **描述**: 已连接状态下按所选 QoS 与 Retain 发布；Payload 支持文本、JSON、Base64、Hex 四种格式，JSON 可一键美化。可按间隔秒数定时循环发布，切换查看其它连接时后台仍继续。定时发布读该连接已保存的发布字段；界面正在查看该连接时会先把底部表单写回配置

### 发布预设
- **目的**: 在几组常用报文之间快速切换
- **描述**: 每条连接有一份可增减预设，放在独立页面编辑。会话页底部表单下方按列表展示发送按钮，固定一行，超出时横向滑动。点哪条就发哪组 Topic、Payload、QoS、Retain 与格式，不改底部表单，也不改正在运行的定时发布。旧配置缺该字段时列表为空

### 自动回复
- **目的**: 收到指定 Topic / 内容后立刻回一条固定报文
- **描述**: 每条连接有一份可增减规则，放在独立页面编辑。每条规则自带启用勾选、匹配 Topic 过滤器、Payload 包含文本，以及固定回复的 Topic / Payload / QoS / Retain / 格式。Broker 推来消息后先记 RECV，再按列表顺序评估已勾选规则，第一条命中即发送该条自己的回复。自身回投可选跳过或再匹配

### 消息日志
- **目的**: 观察调试过程
- **描述**: 按连接分别记录连接事件、收发消息与错误信息，收发消息以聊天气泡左右对齐。每连接内存日志上限 200 条。可用搜索框和类型筛选过滤展示；接收显示格式可切换文本/JSON/Base64/Hex，支持清空、保存为文件，以及自动滚动开关。筛选只影响界面，保存仍导出该连接全部记录

### 皮肤与语言
- **目的**: 按使用场景切换配色与界面语言
- **描述**: 设置页可切换跟随系统、黑、白、蓝、绿、紫皮肤，以及中文 / English。跟随系统时按操作系统深浅色在黑、白之间切换。选择写入 `mqttc.json`。Windows 标题栏颜色跟随当前皮肤

### 关于
- **目的**: 查看项目介绍、使用说明摘要与版本号
- **描述**: 左侧栏「设置」下方进入独立关于页，展示 mqttc 简介、主要能力、配置与平台说明、`Cargo.toml` 中的版本号、MIT 开源协议，以及 Made with Slint 署名

### 配置持久化
- **目的**: 下次打开时自动恢复上次的连接与参数
- **描述**: 全部连接与界面偏好写入可执行文件同目录的 `mqttc.json`，启动时自动加载，旧版单连接配置自动迁移。缺发布预设或自动回复字段时对应列表为空；自身回投缺省为跳过
