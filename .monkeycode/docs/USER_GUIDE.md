# 使用说明

跨平台桌面 MQTT 调试客户端。Windows 与 Linux 可直接运行预编译文件；macOS 需在本机编译。协议支持 MQTT 3.1.1 与 MQTT 5.0。

## 界面结构

左侧始终是连接列表。右侧按页切换：

- 连接配置：名称、主机、端口、协议、认证、Keep Alive、超时、Clean Session、SSL/TLS、Last Will
- 会话：订阅栏、聊天气泡日志、底部发布表单、预设发送按钮
- 自动回复：自身回投策略与规则列表
- 发布预设：可增减的报文列表
- 设置：皮肤与界面语言
- 关于：项目介绍、说明与版本号

点 `+` 或「编辑」进入连接配置。点「自动回复」「发布预设」「设置」或「关于」进入对应页，再点「返回会话」回到会话页。

## 连接

1. 左侧点 `+`，填写名称、主机与端口（默认 `127.0.0.1:1883`），选择 MQTT 3.1.1 或 5.0
2. 需要认证时填写用户名和密码，留空则匿名连接。同一页还可设置 Keep Alive、连接超时、Clean Session、SSL/TLS 与 Last Will。勾选 SSL 会把默认端口切到 8883。MQTT 5.0 的 Clean Session 对应 Clean Start
3. Client ID 留空会在连接时自动生成
4. 点右上角「连接」。成功后自动进入会话页。多个连接可同时在线，点左侧条目切换
5. 删除连接：点左侧条目右侧的 `×`

## 订阅与日志

会话页左侧是订阅栏：选择 QoS 后点「订阅」。点击某条订阅可按该 Topic（含 `+` / `#`）筛选消息，再点一次取消筛选。点条目右侧 `×` 取消订阅。重连后会按已保存列表自动再订。

中间是聊天气泡。右上角可切换接收格式、消息类型（全部 / 收 / 发 / 系统 / 错误）、搜索关键字，以及「自动滚动」。筛选只影响界面展示。

「保存日志」把当前连接的全部内存记录导出为 `logs/mqttc-YYYYMMDD-HHMMSS.log`，每行带完整时间戳：

```
[2026-09-15 10:20:30] [RECV] mqttc/mvp/hello hello from mqttc
```

每条连接内存中最多保留 200 条；「清空」只清当前连接。

## 发布

底部发布栏一行放下 Topic、QoS、Retain、格式和定时，下面是 payload 输入框。点「发布」按表单发送。点「美化」按 JSON 格式化编辑框。

Payload 格式：

- 文本：原样发送
- JSON：发送前校验合法性
- Base64 / Hex：编辑框内容按该编码解码为字节后发送

定时发布使用该连接底部表单对应的 Topic、Payload、QoS、Retain 与格式，间隔 1 到 3600 秒。切换查看其它连接时，这条连接的定时发布在后台继续，仍用它自己保存的字段。

## 发布预设

左侧栏「发布预设」（在「自动回复」下方）打开独立页面，编辑当前连接自己的列表。点「新增预设」追加一条空名称、空 Topic、空 Payload、QoS 0、Retain 关闭、格式为文本的预设。可删除任意一条。未连接时仍可增删和编辑。

会话页底部发布表单下方按列表展示发送按钮，固定一行；按钮超出时横向滑动，不撑高发布区。名称为空时按钮显示「预设 1 / 2 / …」（英文 Preset 1 / 2 / …）。点对应按钮即用该组参数发布，不改底部表单，也不改正在跑的定时发布。未连接时发送按钮不可用。列表为空时会话页不显示这排按钮。

## 自动回复

左侧栏「自动回复」打开独立页面，编辑的是当前连接自己的规则。

1. 点「新增规则」追加一条默认未勾选、字段为空、QoS 0、Retain 关闭、格式为文本的规则
2. 勾选「启用」后该条才参与匹配。取消勾选只影响这一条
3. 「匹配 Topic」支持 MQTT `+` / `#`。为空则该条被跳过
4. 「包含」按入站 Payload 的 UTF-8 文本区分大小写查找。留空表示 Topic 命中即可
5. 命中后只发这一条自己的回复 Topic / Payload / QoS / Retain / 格式。同一条入站消息只触发列表中第一条命中的已勾选规则
6. 未连接时仍可增删和编辑；连接后才会真正发送
7. 自动发出的报文出现在日志里，种类为 SEND，底部表单和全部发布预设保持原样

自身回投：

- 「跳过自身回投」（默认）：刚发出的自动回复被 Broker 回投到本连接时，仍记 RECV，但本轮不再匹配规则
- 「再匹配自身回投」：回投与其它入站一样重新走规则。规则若再次命中自己，可能形成循环，请按现场协议选用

回复 Topic 为空、JSON / Base64 / Hex 编码失败或发送失败时写 ERR，本轮结束，后面的规则不再看。

## 设置

左侧连接列表底部进入「设置」。皮肤：跟随系统、黑、白、蓝、绿、紫。跟随系统时按操作系统深浅色在黑、白之间切换。蓝色为海军蓝、绿色为青绿、紫色为深紫罗兰。界面语言：中文 / English，切换立即生效。选择写入 `mqttc.json`。Windows 标题栏颜色跟随当前皮肤。

## 关于

左侧栏「设置」下方进入「关于」。页面展示项目介绍、主要能力说明、当前版本号（与 `Cargo.toml` 一致）、MIT 开源协议，以及 Made with Slint 署名。点「返回会话」回到会话页。

## 配置文件

全部连接与界面偏好写入可执行文件同目录的 `mqttc.json`，下次打开自动加载。旧版单连接配置会自动迁移。缺发布预设或自动回复字段时对应列表为空；自身回投缺省为跳过。已有预设条数保持原样。
