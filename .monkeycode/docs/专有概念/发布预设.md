# 发布预设

每个连接固定保存恰好 3 个发布预设，展示在会话页底部发布表单下方。

## 字段

`PublishPreset`：名称、Topic、Payload、QoS、Retain、格式（`text` / `json` / `base64` / `hex`）。尚未填写时全部为空，QoS 0，Retain 关闭，格式文本。名称为空时界面标签为「预设 1 / 2 / 3」或 `Preset 1 / 2 / 3`。

## 发送

点某行「发送」走 `publish_from_preset`：用该行自己的字段编码并发布。成功记 SEND。不把内容拷进底部 `pub_topic` / `pub_payload`，也不改正在运行的定时发布。定时发布始终读底部表单。

未连接或 Topic 为空、编码失败时拒绝发送并写 ERR。未连接时仍可编辑这 3 行。

## 持久化

加载旧 `mqttc.json` 时若缺该字段，补齐 3 个空预设；多于 3 个则截断。切换连接时展示该连接自己的 3 行。
