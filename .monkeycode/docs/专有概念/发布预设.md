# 发布预设

每条连接保存一份可增减的预设列表，在独立页面（`page == 4`）编辑。会话页底部发布表单下方只放发送按钮，固定一行，超出时横向滑动。

## 字段

`PublishPreset`：名称、Topic、Payload、QoS、Retain、格式（`text` / `json` / `base64` / `hex`）。新增时全部为空，QoS 0，Retain 关闭，格式文本。名称为空时会话页按钮标签为「预设」加从 1 起的序号，或英文 `Preset` 加序号。

## 编辑

左侧栏「发布预设」打开页 4。可新增、删除、改字段。未连接时仍可编辑。列表允许为空。

## 发送

会话页点对应发送按钮走 `publish_from_preset`：用该条自己的字段编码并发布。成功记 SEND。不把内容拷进底部 `pub_topic` / `pub_payload`，也不改正在运行的定时发布。定时发布读该连接已保存的 `pub_*` 字段。

未连接或 Topic 为空、编码失败时拒绝发送并写 ERR。未连接时发送按钮不可用。

## 持久化

加载旧 `mqttc.json` 时若缺该字段，列表为空。已有条数保持原样，不截断、不补齐。切换连接时展示该连接自己的列表。
