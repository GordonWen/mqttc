# 自动回复

每条连接保存一份可增减的规则列表，以及连接级自身回投策略。规则在独立页面（`page == 3`）编辑，不占用会话页的订阅、日志和发布区。

## 规则字段

一条 `AutoReplyRule` 自包含：

- `enabled`：行首复选框，默认未勾选
- `match_topic`：MQTT 过滤器；去空白后为空则跳过
- `payload_contains`：空表示任意 Payload；非空则对 UTF-8 文本做区分大小写包含
- `reply_topic` / `reply_payload` / `qos` / `retain` / `format`：命中后只发这一组

规则 N 只用规则 N 的条件，也只发规则 N 的报文。编辑或勾选规则 N 不改写规则 M。

## 评估顺序

1. Broker 推来 PUBLISH，先按现有路径记 RECV
2. 若自动回复页可见且是当前连接，先把界面规则同步进配置
3. Echo Policy 为 skip 且入站等于最近一次 Fixed Reply 的 Topic 与原始字节：结束本轮
4. 按列表顺序找第一条已勾选且匹配的规则
5. 回复 Topic 为空或编码失败：ERR，结束本轮
6. `MqttHandle.publish` 成功：SEND 日志，更新 `last_auto_reply`；失败：ERR，不更新该槽，本轮仍结束

未连接时页面可编辑，不发送。手动发布、发布预设、定时发布走原路径，不读规则，也不写入 `last_auto_reply`。

## 自身回投

`ConnRuntime.last_auto_reply` 只记录最近一次自动回复发出的 `(topic, payload_bytes)`。比较原始字节，不按显示格式解码。断开或删除连接时清空。连接开始时也会清空。

Echo Policy 存在 `ConnectionConfig.auto_reply_echo`：`skip`（默认）或 `rematch`。未知值按 skip。
