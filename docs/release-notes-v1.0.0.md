# mqttc v1.0.0

一个简单轻便易用的 MQTT 调试客户端。免安装，解压即用。

v1.0.0 是首个稳定版：保留原有配置格式，新增自定义配色、界面字号、无边框窗口与
全新的应用图标。

## 下载

| 平台 | 文件 |
|---|---|
| Windows 10/11 x64 | `mqttc-v1.0.0-windows-x64.zip` |
| Linux x64（glibc 2.35+） | `mqttc-v1.0.0-linux-x64.tar.gz` |
| macOS 11+（Apple Silicon / Intel） | `mqttc-v1.0.0-macos-universal.zip` |

解压后运行 `mqttc`（macOS 打开 `mqttc.app`）。配置与导出的日志写在可执行文件同目录，
不写注册表、不写用户目录。

## 本版亮点

### 新图标

- 重新绘制 512 px SVG 母版：蓝色圆角底、白色消息气泡与遥测脉冲
- 导出 16 / 24 / 32 / 48 / 64 / 128 / 256 / 512 多尺寸 PNG，小尺寸适当加粗脉冲线
- 窗口图标、应用内标识与 `mqttc.exe` 资源图标统一为新图标

### 无边框窗口

- 自绘标题栏：品牌标识、最小化 / 最大化 / 关闭、双击标题栏最大化
- 四边与四角可拖拽缩放；Windows 下最大化贴合显示器工作区，适配高 DPI
- 隐藏侧栏后仍可连续调整窗口宽度

### 自定义配色

- 新增第 7 套皮肤“自定义”：27 个颜色槽，覆盖窗口、面板、文字、气泡、强调色等
- 首次切换时从当前皮肤取色；可选择基础皮肤，点色块或输入 `#rrggbb`
- 无效值自动回退到基础皮肤；支持单槽重置与“按基础重置”
- 配置写入 `mqttc.json` 的 `custom_palette`，可与他人分享

### 界面字号

- 4 档字号（小 / 标准 / 大 / 特大），按比例缩放整个界面并持久化
- 适合高分屏或需要放大文字的场景；切换语言、皮肤后保持生效

### 发布预设

- 预设支持置顶（☆ / ★），置顶项排在发布条最前，编辑页顺序不变
- 预设条按名称自然宽度排列，放不下时折叠为“更多预设”
- 长名称自动省略，悬停显示完整名称

### TLS 信任策略

- 关闭“校验服务器证书”时完全忽略 CA 路径，也不加载系统根证书，接受任意证书；
  CA 文件缺失不再阻止连接
- 开启校验且填写 CA 时只信任该 CA；未填写时使用系统根证书
- 连接设置页在“校验服务器证书”右侧直接显示当前策略

### 修复

- 定时发布先记录“已启动”系统日志，再发送首条；首条失败时自动停止并提示
- 侧栏隐藏后的窗口最小宽度计算错误

## 功能

- 多连接管理，每条连接独立会话
- MQTT 3.1.1 / 5.0，QoS 0/1/2、Clean Session、Keep Alive、Last Will
- TLS：系统根证书、自定义 CA（仅信任该 CA）、客户端证书 / 私钥、跳过校验
- 订阅通配符、按 QoS 订阅、No Local / Retain As Published，点击订阅项筛选日志
- 文本 / JSON / Base64 / Hex 发布与互转，JSON 美化
- 定时发布、发布预设（可置顶）、按主题 / 关键字 / 负载自动回复
- 聊天式日志：搜索、筛选、格式切换、自动滚动、暂停、复制、导出；默认 200 条，可调至 2000
- 中英文界面，7 套皮肤（含自定义配色），4 档界面字号
- 便携：`mqttc.json` 与 `logs/` 均在 exe 同目录

## 轻量

Windows x64 release 实测（3 次独立进程中位数）：

| 场景 | 工作集 |
|---|---|
| 启动空闲 | 28.8 MB |
| 连接 + 200 条日志 | 30.8 MB |
| 10 msg/s 流式接收 | 30.8 MB |
| 1 Hz 定时发布 | 31.2 MB |

exe 5.95 MB，portable zip 2.82 MB；空闲 CPU 接近 0%。对比数据见仓库
`docs/BENCHMARK.md`。

## 说明

- 构建未签名。macOS 首次打开请右键 → 打开，或执行
  `xattr -dr com.apple.quarantine mqttc.app`。
- Linux 需要 `libxkbcommon`、Wayland 或 X11、`fontconfig`；详见包内 READ-ME。
- 校验：每个资产附 `.sha256`，Release 中另有 `SHA256SUMS.txt`（含三平台）。
- 升级无需迁移：直接替换可执行文件，原 `mqttc.json` 继续可用；新字段缺失时使用默认值。
